## 작성 규칙

- 파일 이름: `{4자리 번호}-{영문 kebab-case 제목}.md`
- 상태: **제안** → **승인** / **기각**. 나중에 바뀌면 기존 ADR은 지우지 않고 상태를 **대체됨 (ADR-xxxx)** 으로 바꾸고 새 ADR을 쓴다.
- 기획 문서를 바꾸는 결정을 새로 내리면 ADR을 함께 쓴다.
