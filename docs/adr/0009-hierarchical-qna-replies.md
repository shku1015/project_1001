# ADR-0009. QnA는 계층형 답글 구조

- 상태: 승인
- 날짜: 2026-10-04
- 관련 문서: [03-domain-erd.md](../03-domain-erd.md) 6절 `TB_POST`, [04-features/05-board.md](../04-features/05-board.md) 5.3

## 맥락

처음 ERD에서는 QnA 답변을 게시글당 1개로 보고 게시글 테이블에 답변 칼럼(내용, 답변자, 일시)을 두었다. 사용자는 **답글과 재답글**이 가능해야 한다고 정했다.

## 검토한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| 게시글에 답변 칼럼 1개 (1차 설계) | 단순 | 추가 질문·재답변 불가 |
| 답변 전용 테이블 (1 : N) | 원글과 답변 분리 | 답변에 대한 답변(재답글) 표현이 어려움 |
| **게시글 테이블 자기 참조 (계층형)** | 답글·재답글을 같은 구조로 표현. 첨부도 같은 방식 | 정렬·트리 조회 로직이 필요 |

## 결정

- 원글과 답글을 `TB_POST` 한 테이블에 두고 `ROOT_POST_ID`, `PARENT_POST_ID`, `DEPTH`, `THREAD_ORD`로 연결한다.
- 답글은 **원글 작성자와 관리자만** 달 수 있다. 깊이 제한은 없다 (화면은 깊이 5부터 들여쓰기 고정).
- 답변 상태는 원글에만 둔다. 관리자 답글 → "답변완료", 그 뒤 원글 작성자 재답글 → "답변대기".
- 답글이 달린 글을 지우면 "삭제된 글입니다"로 표시하고 답글은 남긴다.

## 결과

- 좋은 점: 회원과 관리자가 여러 번 주고받는 문의를 그대로 담을 수 있다.
- 감수할 점: 답글을 중간에 넣을 때 `THREAD_ORD`를 다시 매겨야 한다. 목록은 원글만, 상세는 트리로 조회하는 쿼리가 필요하다.
