# ADR-0017. 전자정부프레임워크 5.0.2로 고정

- 상태: 승인
- 날짜: 2026-10-04
- 관련 문서: [08-architecture.md](../08-architecture.md) 3절

## 맥락

처음에는 "개발 시작 시점의 최신 안정화 버전"으로만 정했다. 하네스 엔지니어링(에이전트가 빌드·테스트로 스스로 검증하는 개발)을 하려면 누가 언제 빌드해도 같은 결과가 나와야 하므로, 버전을 숫자로 고정해야 한다. 메이저 버전에 따라 Java, Spring, 서블릿 패키지가 달라져 설계에도 영향을 준다.

## 검토한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| 최신 안정화 버전을 그때그때 사용 | 항상 최신 | 빌드 결과가 시점마다 달라짐 |
| 4.x | 자료가 많음 | `javax.*`, Spring 5 기반. 이후 이전 작업 필요 |
| **5.0.2로 고정** | 재현 가능한 빌드. Spring Boot 3·Java 17·Jakarta EE 기반 | 5.x 관련 자료가 4.x보다 적을 수 있음 |

## 결정

- 전자정부프레임워크 **5.0.2**로 고정한다.
- Java, Spring Boot, Spring Security 등 하위 버전은 5.0.2가 지정하는 버전을 따르고, 프로젝트 생성 시 확인해 08 문서 3절에 숫자로 기록한다.

## 결과

- 좋은 점: 빌드·테스트가 재현 가능하다. 함께 쓰는 라이브러리(Spring Session, springdoc, Flyway, Testcontainers) 버전을 이 기준으로 맞춘다.
- 감수할 점: Jakarta EE 기반이라 JSP·JSTL 의존성도 Jakarta 버전을 써야 한다. 오래된 `javax.*` 예제 코드는 그대로 쓸 수 없다. 버전을 올리려면 새 ADR이 필요하다.
