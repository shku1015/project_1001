# ADR-0014. 전자정부프레임워크 공통컴포넌트 테이블을 쓰지 않음

- 상태: 승인
- 날짜: 2026-10-04
- 관련 문서: [03-domain-erd.md](../03-domain-erd.md), [08-architecture.md](../08-architecture.md) 7.1

## 맥락

전자정부프레임워크는 공통코드, 첨부파일, 게시판, 권한 등에 대한 공통컴포넌트와 테이블을 제공한다. 이번 서비스에도 같은 영역(코드, 첨부, 게시판, 권한)이 있다.

## 검토한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| 공통컴포넌트 테이블·기능 사용 | 빨리 만들 수 있음. 표준 구조 | 이번 요구사항(메뉴 × 액션 권한, 계층형 답글, 게시판별 메뉴, 마스킹 설정)에 맞추려면 많이 고쳐야 함. 구조를 직접 설계하는 학습이 줄어듦 |
| **직접 설계한 테이블 사용** | 요구사항에 정확히 맞음. 설계 과정을 학습 | 직접 구현할 양이 늘어남 |

## 결정

[03-domain-erd.md](../03-domain-erd.md)의 테이블을 직접 만들어 쓴다. 전자정부프레임워크는 실행환경(공통 기반, MyBatis 연동, 보안 등) 위주로 쓴다.

## 결과

- 좋은 점: 테이블과 규칙이 기획 문서와 1 : 1로 맞는다.
- 감수할 점: 공통컴포넌트를 바로 가져다 쓸 수 없다. 나중에 공통컴포넌트를 도입하려면 데이터 이관이 필요하다.
