# ADR-0011. 개인정보 마스킹을 설정으로 관리

- 상태: 승인
- 날짜: 2026-10-04
- 관련 문서: [04-features/10-masking.md](../04-features/10-masking.md), [03-domain-erd.md](../03-domain-erd.md) `TB_MASKING_POLICY`

## 맥락

처음에는 개인정보를 화면에서 항상 마스킹하고, 엑셀에는 `PRIVACY` 권한이 있어도 원문을 넣지 않도록 고정했다. 사용자는 마스킹을 **옵션으로 관리**할 수 있어야 한다고 정했다.

## 검토한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| 고정 규칙 (1차 설계) | 단순, 실수 여지 없음 | 운영 상황에 맞게 바꿀 수 없음 |
| 코드관리의 상세코드 사용 여부로 표현 | 테이블 추가 없음 | 의미가 불분명하고 시스템 코드 보호 규칙과 충돌 |
| **전용 설정 테이블 + 전용 메뉴** | 항목별·용도별(화면/엑셀)로 명확 | 테이블과 메뉴가 하나씩 늘어남 |

## 결정

- `TB_MASKING_POLICY`에 개인정보 항목별 `SCREEN_MASK_YN`, `EXCEL_MASK_YN`을 둔다. 기본값은 모두 마스킹.
- 시스템관리 아래 "마스킹 설정" 메뉴(`MASKING`, 시스템 메뉴)에서 바꾼다.
- 엑셀 마스킹을 꺼도 `PRIVACY` 권한이 있는 관리자에게만 원문이 나간다.
- 마스킹 방식(가리는 위치)은 항목별로 고정한다.

## 결과

- 좋은 점: 배포 없이 정책을 바꿀 수 있다. 설정 변경도 감사로그에 남는다.
- 감수할 점: 마스킹을 끄면 `READ` 권한만으로 원문이 보이므로, 설정 변경 시 경고 확인을 거치게 했다.
