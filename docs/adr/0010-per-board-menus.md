# ADR-0010. 게시판별 관리 메뉴 자동 생성

- 상태: 승인
- 날짜: 2026-10-04
- 관련 문서: [04-features/05-board.md](../04-features/05-board.md) 1절, [02-access-model.md](../02-access-model.md) 4절

## 맥락

게시판은 설정으로 여러 개 만든다. 처음에는 "게시글 관리" 메뉴 하나에서 게시판을 골라 관리하도록 설계했다. 사용자는 **생성된 게시판별로도** 관리할 수 있어야 한다고 정했다. 그러면 "공지사항만 관리하는 운영자"처럼 게시판 단위 권한도 줄 수 있다.

## 검토한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| 통합 메뉴 하나 | 단순 | 게시판 단위로 권한을 나눌 수 없음 |
| 게시판별 메뉴만 | 게시판 단위 권한 | 모든 게시판을 한곳에서 볼 수 없음 |
| **통합 메뉴 + 게시판별 메뉴 자동 생성** | 둘 다 가능 | 권한 확인이 "둘 중 하나" 방식이 됨 |

## 결정

- 메뉴: 게시판 관리(`BOARD`), 통합 게시글 관리(`POST`), 게시판별 게시글 관리(`POST_{게시판 코드}`, 게시판 등록 시 자동 생성).
- 게시글 기능은 `POST` 또는 해당 `POST_{게시판 코드}` 중 하나의 권한이 있으면 통과한다.
- 게시판별 메뉴는 게시판 관리에서만 만들고 지운다. 메뉴관리에서는 이름·순서·아이콘만 바꾼다.
- 게시판 코드는 메뉴 코드에 쓰이므로 등록 후 바꿀 수 없다.

## 결과

- 좋은 점: 게시판 단위로 담당자를 나눌 수 있다. 화면은 통합·게시판별이 같은 것을 쓴다.
- 감수할 점: `@RequirePermission`이 여러 메뉴를 받도록 확장해야 한다. 게시판 삭제·사용 안 함이 메뉴와 권한, 역할 매핑까지 연쇄로 바꾼다.
