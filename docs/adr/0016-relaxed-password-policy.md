# ADR-0016. 비밀번호 규칙을 학습용으로 완화

- 상태: 승인
- 날짜: 2026-10-04
- 관련 문서: [07-nonfunctional.md](../07-nonfunctional.md) 1.1·1.2

## 맥락

비기능 초안에서는 일반적인 관리자 비밀번호 규칙(8~20자, 3종류 이상, 아이디 포함 금지, 반복·연속 문자 금지, 90일 변경 주기, 임시 비밀번호 12자·4종류)을 제안했다. 이 서비스는 학습 프로젝트이고, 개발·테스트 중에 계정을 자주 만들고 로그인한다.

## 검토한 대안

| 대안 | 장점 | 단점 |
|---|---|---|
| 일반적인 강한 규칙 (초안) | 실제 운영 수준 | 테스트가 번거로움 |
| **최소 규칙** | 테스트가 편함 | 운영 보안 수준에 못 미침 |

## 결정

- 관리자 비밀번호: **1~20자**, 문자 종류 1종류 이상. 현재 비밀번호와 같은 값만 금지.
- 아이디 포함 금지, 반복·연속 문자 금지, **변경 주기는 두지 않는다**. 비밀번호 변경 강제는 임시 비밀번호일 때만.
- 임시 비밀번호: 길이는 설정값(1자 이상, 기본 12자), 문자 종류 조건 없음.
- 저장은 BCrypt 해시, 로그인 5회 실패 시 잠금, 동시 로그인 금지는 그대로 둔다.

## 결과

- 좋은 점: 개발·테스트 중 계정 관리가 쉽다.
- 감수할 점: 실제 운영에는 부적합하다. **운영에 쓴다면 이 ADR을 대체하는 새 ADR로 규칙을 강화해야 한다.**
