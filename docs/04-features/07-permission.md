# 04-07. 관리자 권한관리

## 1. 개요

권한(메뉴 × 액션)은 메뉴관리에서 자동으로 생기므로, 이 화면에서는 권한을 만들거나 지우지 않는다.
대신 **메뉴 기준**으로 권한을 보고, 어떤 역할이 그 권한을 가졌는지 확인·조정한다.

| 화면 | 기준 | 쓰임 |
|---|---|---|
| 역할관리 ([08-role.md](08-role.md)) | 역할 기준 | "이 역할은 어떤 권한을 가졌나" |
| 권한관리 (이 문서) | 메뉴 기준 | "이 메뉴는 어떤 역할이 쓸 수 있나" |

두 화면은 같은 데이터(`TB_ROLE_PERMISSION`)를 다른 방향에서 보고 고친다.

- 관련 테이블: `TB_PERMISSION`, `TB_ROLE_PERMISSION`, `TB_MENU`, `TB_ROLE`

## 2. 권한

| 기능 | 액션 |
|---|---|
| 권한 목록, 역할별 부여 현황 조회 | `READ` |
| 메뉴 기준 역할 부여·회수 | `UPDATE` |

## 3. 기능 목록

| ID | 기능 | 설명 |
|---|---|---|
| PRM-01 | 권한 목록 조회 | 메뉴 트리 순서로 메뉴별 사용 액션을 표시 |
| PRM-02 | 메뉴별 역할 부여 현황 | 메뉴를 고르면 "역할 × 액션" 표로 부여 여부 표시 |
| PRM-03 | 메뉴 기준 일괄 부여·회수 | PRM-02 표에서 체크박스를 바꿔 저장 |
| PRM-04 | 관리자별 최종 권한 조회 | 관리자를 고르면 역할을 합친 최종 권한을 메뉴 × 액션 표로 표시 (확인용) |

## 4. 비즈니스 규칙

| ID | 규칙 |
|---|---|
| BR-01 | 권한은 이 화면에서 만들거나 지우지 않는다. 메뉴관리에서 사용 액션을 바꾼다 |
| BR-02 | `READ`가 아닌 권한을 부여하면 같은 메뉴의 `READ`도 함께 부여한다. `READ`를 회수하면 같은 메뉴의 다른 권한도 함께 회수한다 |
| BR-03 | 시스템 역할(슈퍼관리자)은 표에 표시만 하고 바꿀 수 없다 |
| BR-04 | 본인이 가진 역할의 권한은 바꿀 수 없다 (자기 권한 상향 방지). 슈퍼관리자는 예외 |
| BR-05 | 본인이 갖지 않은 권한은 다른 역할에 부여할 수 없다 (R5). 슈퍼관리자는 예외 |
| BR-06 | 권한 변경은 해당 역할을 가진 관리자의 다음 요청부터 반영된다 |
