# 04-04. 코드관리

## 1. 개요

서비스 전반에서 쓰는 상태값·구분값을 그룹코드와 상세코드 2단계로 관리한다.

- 관련 테이블: `TB_CODE_GROUP`, `TB_CODE`
- 초기 코드 그룹은 [03-domain-erd.md](../03-domain-erd.md) 5절을 따른다.

## 2. 권한

| 기능 | 액션 |
|---|---|
| 그룹코드·상세코드 조회 | `READ` |
| 등록 | `CREATE` |
| 수정, 순서 변경 | `UPDATE` |
| 삭제 | `DELETE` |

## 3. 기능 목록

| ID | 기능 | 설명 |
|---|---|---|
| COD-01 | 그룹코드 목록 조회 | 검색 조건: 그룹코드, 그룹코드명, 사용 여부. 그룹코드 오름차순 정렬 |
| COD-02 | 그룹코드 등록 | 그룹코드, 이름, 설명 입력 |
| COD-03 | 그룹코드 수정 | 이름, 설명, 사용 여부 수정 |
| COD-04 | 그룹코드 삭제 | 상세코드가 없고 시스템 코드가 아닐 때만 삭제 |
| COD-05 | 상세코드 목록 조회 | 그룹코드를 고르면 그 아래 상세코드를 정렬 순서대로 표시 |
| COD-06 | 상세코드 등록 | 코드, 이름, 정렬 순서, 설명 입력 |
| COD-07 | 상세코드 수정 | 이름, 정렬 순서, 설명, 사용 여부 수정 |
| COD-08 | 상세코드 삭제 | 시스템 코드 그룹이 아닐 때만 삭제 |

## 4. 비즈니스 규칙

| ID | 규칙 |
|---|---|
| BR-01 | 그룹코드와 상세코드는 영문 대문자, 숫자, `_`만 쓴다. 등록 후 바꿀 수 없다 |
| BR-02 | 같은 그룹 안에서 상세코드는 중복될 수 없다 |
| BR-03 | 시스템 코드 그룹(`SYSTEM_YN = 'Y'`)은 프로그램이 직접 참조한다. 그래서 그룹 삭제, 상세코드 추가·삭제, 사용 여부 변경을 할 수 없고, 이름·정렬 순서·설명만 바꿀 수 있다 |
| BR-04 | 시스템 코드 여부는 화면에서 바꿀 수 없다. 초기 데이터로만 정한다 |
| BR-05 | 일반 코드의 상세코드는 실제 삭제한다. 이미 데이터에서 쓰고 있을 수 있으므로, 삭제 대신 사용 여부를 `N`으로 바꾸도록 안내한다 |
| BR-06 | 사용 여부가 `N`인 코드는 선택 목록(콤보박스)에 나오지 않지만, 이미 저장된 데이터의 표시에는 계속 쓴다 |
| BR-07 | 코드를 바꾸면 화면에 바로 반영되어야 한다 (코드가 바뀌면 코드 캐시를 비운다. [08-architecture.md](../08-architecture.md) 6절) |

## 5. 다른 기능에서의 사용

- 모든 화면의 코드 콤보박스와 코드명 표시는 코드관리 데이터를 쓴다.
- 프론트 3종이 같은 방식으로 쓰도록 "그룹코드로 상세코드 목록 조회" 기능을 공통으로 제공한다 (06 API 명세).
- 게시판 분류(FAQ 분류 등)는 일반 코드 그룹으로 만들어 게시판 설정에서 연결한다 ([05-board.md](05-board.md)).
