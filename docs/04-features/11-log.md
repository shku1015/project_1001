# 04-11. 감사로그·로그인 이력 조회

## 1. 개요

감사로그(`TB_AUDIT_LOG`)와 관리자 로그인 이력(`TB_ADMIN_LOGIN_HIST`)을 조회한다. 로그는 조회만 하고 수정·삭제하지 않는다.

- 메뉴 코드: `AUDIT_LOG` (시스템관리 아래, 시스템 메뉴)
- 기록 대상은 각 기능 문서의 "감사로그" 절을 따른다.

## 2. 권한

| 기능 | 액션 |
|---|---|
| 감사로그·로그인 이력 조회 | `READ` |
| 엑셀 다운로드 | `EXCEL` |

## 3. 기능 목록

| ID | 기능 | 설명 |
|---|---|---|
| LOG-01 | 감사로그 목록 조회 | 검색 조건: 작업 기간(필수), 관리자, 메뉴, 액션, 대상 종류, 대상 ID |
| LOG-02 | 감사로그 상세 조회 | 요약, 사유, 변경 전·후 데이터 비교 |
| LOG-03 | 감사로그 엑셀 다운로드 | 검색 결과 다운로드 (변경 전·후 데이터는 제외) |
| LOG-04 | 로그인 이력 목록 조회 | 검색 조건: 기간(필수), 로그인 아이디, 결과, IP |
| LOG-05 | 로그인 이력 엑셀 다운로드 | 검색 결과 다운로드 |

## 4. 비즈니스 규칙

| ID | 규칙 |
|---|---|
| BR-01 | 조회 기간은 필수이며 최대 3개월이다. 기본값은 최근 7일 |
| BR-02 | 로그는 수정·삭제할 수 없다. 화면에도 수정·삭제 기능을 두지 않는다 |
| BR-03 | 변경 전·후 데이터는 바뀐 항목만 강조해서 보여 준다 |
| BR-04 | 감사로그 조회 자체는 기록하지 않는다. 엑셀 다운로드는 기록한다 |
| BR-05 | 관리자 상세 화면의 로그인 이력(ADM-09)은 이 메뉴 권한이 없어도 관리자관리 `READ`로 볼 수 있다. 최근 20건만 보여 준다 |

## 5. 감사로그

| 엑셀 다운로드 | 검색 조건, 건수 |
