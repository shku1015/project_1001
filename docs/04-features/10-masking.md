# 04-10. 개인정보 마스킹 설정

## 1. 개요

개인정보 항목별로 화면과 엑셀에서 마스킹할지를 설정으로 관리한다.
코드 배포 없이 운영 중에 마스킹 정책을 바꿀 수 있다.

- 관련 테이블: `TB_MASKING_POLICY`, `TB_CODE` (코드 그룹 `PRIVACY_FIELD`)
- 메뉴 코드: `MASKING` (시스템관리 아래)

## 2. 권한

| 기능 | 액션 |
|---|---|
| 설정 조회 | `READ` |
| 설정 변경 | `UPDATE` |

## 3. 기능 목록

| ID | 기능 | 설명 |
|---|---|---|
| MSK-01 | 마스킹 설정 조회 | 개인정보 항목별로 화면 마스킹, 엑셀 마스킹 여부와 마스킹 예시를 표로 표시 |
| MSK-02 | 마스킹 설정 변경 | 항목별 화면 마스킹, 엑셀 마스킹을 켜고 끈다 |

## 4. 설정 항목과 기본값

| 항목 | 화면 마스킹 | 엑셀 마스킹 | 마스킹 예 |
|---|---|---|---|
| 이름 | Y | Y | 홍\*동, 김\* |
| 이메일 | Y | Y | ho\*\*\*@example.com |
| 휴대폰 번호 | Y | Y | 010-\*\*\*\*-5678 |
| 생년월일 | Y | Y | 1990-\*\*-\*\* |

## 5. 적용 규칙

| ID | 규칙 |
|---|---|
| BR-01 | 화면 마스킹이 `Y`인 항목은 목록·상세에서 가려서 보여 준다. `PRIVACY` 권한이 있으면 상세에서 "원문 보기"로 볼 수 있다 |
| BR-02 | 화면 마스킹이 `N`인 항목은 `READ` 권한만 있어도 원문으로 보인다 |
| BR-03 | 엑셀 마스킹이 `Y`인 항목은 누가 내려받든 가린 값으로 내려간다 |
| BR-04 | 엑셀 마스킹이 `N`인 항목은 `PRIVACY` 권한이 있는 관리자에게만 원문으로 내려간다. 권한이 없으면 가린 값으로 내려간다 |
| BR-05 | 마스킹 방식(가리는 위치와 길이)은 항목별로 고정이며 설정으로 바꾸지 않는다 |
| BR-06 | 정보 수정 화면은 마스킹 설정과 상관없이 원문을 보여 주므로 `PRIVACY` 권한이 필요하다 ([02-user.md](02-user.md) BR-05) |
| BR-07 | 설정을 바꾸면 다음 요청부터 바로 반영된다 |
| BR-08 | 개인정보 항목 목록은 코드 그룹 `PRIVACY_FIELD`(시스템 코드)로 정해져 있어 화면에서 추가·삭제하지 않는다 |
