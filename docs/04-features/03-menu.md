# 04-03. 메뉴 동적관리

## 1. 개요

관리자 화면의 메뉴 트리를 DB로 관리한다. 메뉴를 등록하면 그 메뉴의 권한이 함께 만들어진다.
메뉴와 권한의 관계는 [02-access-model.md](../02-access-model.md) 3절을 따른다.

- 관련 테이블: `TB_MENU`, `TB_PERMISSION`, `TB_ROLE_PERMISSION`

## 2. 권한

| 기능 | 액션 |
|---|---|
| 메뉴 트리·상세 조회 | `READ` |
| 메뉴 등록 | `CREATE` |
| 메뉴 수정, 순서 변경 | `UPDATE` |
| 메뉴 삭제 | `DELETE` |

## 3. 기능 목록

| ID | 기능 | 설명 |
|---|---|---|
| MNU-01 | 메뉴 트리 조회 | 전체 메뉴를 트리로 표시. 사용 안 하는 메뉴도 흐리게 표시 |
| MNU-02 | 메뉴 상세 조회 | 트리에서 메뉴를 고르면 상세 정보와 사용 중인 액션 표시 |
| MNU-03 | 메뉴 등록 | 상위 메뉴를 고르고 하위 메뉴로 등록. 화면 메뉴는 사용할 액션 선택 |
| MNU-04 | 메뉴 수정 | 메뉴명, URL, 아이콘, 사용 여부, 사용 액션 수정 |
| MNU-05 | 상위 메뉴 변경 | 메뉴를 다른 폴더 아래로 옮긴다 |
| MNU-06 | 순서 변경 | 같은 상위 메뉴 안에서 드래그 또는 ▲▼ 버튼으로 순서를 바꾸고, [순서 저장]을 눌러야 저장한다 |
| MNU-07 | 메뉴 삭제 | 하위 메뉴가 없을 때만 삭제 |

## 4. 비즈니스 규칙

| ID | 규칙 |
|---|---|
| BR-01 | 메뉴 트리는 최대 3단계까지 만들 수 있다 |
| BR-02 | 폴더 메뉴 아래에만 하위 메뉴를 둘 수 있다. 화면 메뉴 아래에는 둘 수 없다 |
| BR-03 | 메뉴 코드는 영문 대문자, 숫자, `_`만 쓰고 중복될 수 없다. 서버 코드에서 권한 체크에 쓰므로 **등록 후 바꿀 수 없다** |
| BR-04 | 메뉴 종류(폴더 / 화면)는 등록 후 바꿀 수 없다 |
| BR-05 | 화면 메뉴는 URL과 사용 액션(최소 `READ`)이 필수다. 폴더 메뉴는 URL과 액션이 없다 |
| BR-06 | 사용 액션을 추가하면 권한이 생기고, 기존 역할에는 자동으로 부여하지 않는다 |
| BR-07 | 사용 액션을 빼면 그 권한과 역할 매핑이 함께 지워진다. 매핑이 있으면 "N개 역할에서 권한이 회수됩니다"라고 확인을 받는다 |
| BR-08 | 하위 메뉴가 있는 메뉴는 삭제할 수 없다. 삭제하면 권한과 역할 매핑까지 실제 삭제한다 |
| BR-09 | 메뉴의 사용 여부를 `N`으로 바꾸면 노출과 접근이 모두 막힌다. 폴더 메뉴를 `N`으로 바꾸면 하위 메뉴도 함께 막힌다 |
| BR-10 | 시스템 메뉴(`SYSTEM_YN = 'Y'`: 메뉴관리, 관리자·역할·권한, 마스킹 설정, 감사로그와 그 상위 폴더, 게시판별 게시글 폴더)는 삭제하거나 사용 안 함으로 바꿀 수 없다. 시스템 메뉴 여부는 초기 데이터로만 정한다 |
| BR-11 | 상위 메뉴를 옮길 때도 BR-01, BR-02를 지켜야 한다 |
| BR-12 | 게시판별 게시글 관리 메뉴(`POST_{게시판 코드}`)는 게시판 관리에서 자동으로 만들고 지운다. 메뉴관리에서는 메뉴명·순서·아이콘만 바꿀 수 있다 ([05-board.md](05-board.md)) |

## 5. 감사로그

| 작업 | 기록 내용 |
|---|---|
| 등록, 수정, 삭제, 상위 메뉴 변경 | 변경 전·후 데이터 |
| 사용 액션 변경 | 추가·제거된 액션, 회수된 역할 목록 |

순서 변경은 기록하지 않는다.
