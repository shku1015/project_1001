# 05-00. 공통 화면

메뉴에 속하지 않는 화면이다. 표 읽는 법은 [README.md](README.md)를 따른다.

## SCR-AUTH-01 로그인

- URL: `/login` · 권한: 없음 (로그인 전)
- 레이아웃: 헤더·왼쪽 메뉴 없이 가운데에 로그인 상자만

| 항목 | 형태 | 필수 | 검증·비고 |
|---|---|---|---|
| 아이디 | 텍스트 | Y | |
| 비밀번호 | 비밀번호 | Y | |

| 버튼 | 동작 |
|---|---|
| 로그인 | 로그인 처리. 실패 시 상자 아래에 메시지 ([04-features/09-auth.md](../04-features/09-auth.md) BR-01, BR-04) |

- 로그인 후 원래 가려던 화면이 있으면 그 화면으로, 없으면 홈으로 간다.
- 임시 비밀번호이면 SCR-AUTH-02로 간다.

## SCR-AUTH-02 비밀번호 변경

- URL: `/password` · 권한: 로그인
- 임시 비밀번호로 로그인한 경우: 헤더·메뉴 없이 표시하고, 바꾸기 전에는 다른 화면으로 갈 수 없다 (로그아웃만 가능)
- 직접 들어온 경우: 일반 레이아웃 안에 표시

| 항목 | 형태 | 필수 | 검증·비고 |
|---|---|---|---|
| 현재 비밀번호 | 비밀번호 | Y | |
| 새 비밀번호 | 비밀번호 | Y | 1~20자 ([07-nonfunctional.md](../07-nonfunctional.md) 1.1). 현재 비밀번호와 달라야 함 |
| 새 비밀번호 확인 | 비밀번호 | Y | 새 비밀번호와 같아야 함 |

| 버튼 | 동작 |
|---|---|
| 변경 | 저장 후 홈으로 이동, "비밀번호가 변경되었습니다" |
| 로그아웃 | 임시 비밀번호 상태일 때만 표시 |

## SCR-HOME 홈

- URL: `/` · 권한: 로그인

| 영역 | 내용 |
|---|---|
| 내 정보 요약 | 이름, 역할, 마지막 로그인 일시와 IP (이번 로그인 직전 기록) |
| 비밀번호 | 마지막 변경일 |
| 바로가기 | 내가 볼 수 있는 화면 메뉴 중 앞쪽 6개 |

사용 가능한 메뉴가 없으면 "사용 가능한 메뉴가 없습니다. 관리자에게 권한을 요청하세요"를 보여 준다.

## SCR-MY-01 내 정보

- URL: `/me` · 권한: 로그인

| 항목 | 형태 | 필수 | 검증·비고 |
|---|---|---|---|
| 로그인 아이디 | 표시 | | 수정 불가 |
| 역할 | 표시 | | 수정 불가 |
| 이름 | 텍스트 | Y | 50자 이내 |
| 이메일 | 텍스트 | Y | 이메일 형식 |
| 휴대폰 번호 | 텍스트 | | 숫자 10~11자리 |
| 부서 | 텍스트 | | 100자 이내 |

| 버튼 | 동작 |
|---|---|
| 저장 | 저장 후 같은 화면, 알림 메시지 |
| 비밀번호 변경 | SCR-AUTH-02로 이동 |

## SCR-ERR-403 / 404 / 500

| 화면 | 메시지 | 버튼 |
|---|---|---|
| 403 권한 없음 | 이 화면을 볼 권한이 없습니다 | 홈으로 |
| 404 페이지 없음 | 요청한 페이지를 찾을 수 없습니다 | 홈으로 |
| 500 오류 | 일시적인 오류가 발생했습니다. 잠시 후 다시 시도하세요 | 홈으로 |

- 로그인이 끊긴 상태에서 요청하면 로그인 화면으로 보낸다 (API 요청이면 `401` 응답 후 프론트가 이동).
