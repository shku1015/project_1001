기능 명세: [04-features/05-board.md](../04-features/05-board.md) · 메뉴 코드: `BOARD`, `POST`, `POST_{게시판 코드}`

| 칼럼 | 데이터 | 정렬 |

| 게시판명 | `BOARD_NM` | ○ |
| 유형 | `BOARD_TYPE_CD` | |

### SCR-BRD-02 게시판 상세

- URL: `/boards/{id}` · 권한: `BOARD` `READ`
- 표시 항목: SCR-BRD-03 입력 항목 전체 + 게시글 수, 관리 메뉴(메뉴명, 누르면 해당 게시글 관리 화면)

| 버튼 | 권한 | 노출 조건 | 동작 |
|---|---|---|---|
| 목록 | `READ` | | 목록으로 |
| 수정 | `UPDATE` | | SCR-BRD-03 (수정) |
| 관리 메뉴 생성 | `UPDATE` | 관리 메뉴 없음 | 확인창 → 메뉴 생성 |
| 관리 메뉴 삭제 | `UPDATE` | 관리 메뉴 있음 | "이 메뉴의 권한이 N개 역할에서 회수됩니다" 확인창 → 메뉴 삭제 |
| 게시글 보기 | `POST` `READ` | | SCR-PST-01을 이 게시판으로 열기 |
| 삭제 | `DELETE` | | "게시글 N건도 사용자 서비스에서 보이지 않게 됩니다" 확인창 → 삭제 후 목록으로 |

### SCR-BRD-03 게시판 등록·수정

- URL: `/boards/new`, `/boards/{id}/edit` · 권한: `BOARD` `CREATE` / `UPDATE`

| 항목 | 칼럼 | 형태 | 필수 | 검증·비고 |
|---|---|---|---|---|
| 게시판 코드 | `BOARD_CD` | 텍스트 | Y | 영문 대문자·숫자·`_`, 50자 이내, 중복 불가. **수정 시 표시만** |
| 게시판명 | `BOARD_NM` | 텍스트 | Y | 100자 이내 |
| 유형 | `BOARD_TYPE_CD` | 코드 콤보 `BOARD_TYPE` | Y | 고르면 아래 옵션에 기본값을 채운다. **수정 시 표시만** |
| 분류 | `CATEGORY_GROUP_CD` | 그룹코드 선택 (일반 코드만) | | 비우면 분류 없음 |
| 회원 글쓰기 | `USER_WRITE_YN` | 라디오 | Y | |
| 댓글 | `COMMENT_YN` | 라디오 | Y | |
| 첨부 | `ATTACH_YN` | 라디오 | Y | |
| 최대 첨부 개수 | `ATTACH_MAX_CNT` | 숫자 | 첨부 사용이면 Y | 1~10, 기본 5 |
| 파일당 최대 크기(MB) | `ATTACH_MAX_SIZE_MB` | 숫자 | 첨부 사용이면 Y | 1~50, 기본 10 |
| 비밀글 | `SECRET_YN` | 라디오 | Y | 1:1문의면 "항상"으로 고정 |
| 답글 | `REPLY_YN` | 라디오 | Y | |
| 관리 메뉴 생성 | (메뉴 생성) | 체크박스 | | **등록 시에만**. 기본 체크 |
| 사용 여부 | `USE_YN` | 라디오 | Y | |

## 2. 게시글 관리

통합 게시글 관리(`/posts`)와 게시판별 게시글 관리(`/posts/{게시판 코드}`)는 **같은 화면**을 쓴다.

| 구분 | 게시판 선택 | 권한 확인 |
|---|---|---|
| 통합 (`/posts`) | 목록 위 게시판 선택 상자로 고른다 (처음에는 첫 게시판) | `POST` 또는 고른 게시판의 `POST_{코드}` |
| 게시판별 (`/posts/NOTICE`) | 고정. 선택 상자 대신 게시판명 표시 | `POST` 또는 `POST_NOTICE` |

이후 URL은 통합 기준으로 적는다. 게시판별은 `/posts/{게시판 코드}/...`로 같은 구조다.

### SCR-PST-01 게시글 목록

- URL: `/posts?board={게시판 코드}` · 권한: `READ`

**검색 조건**

| 항목 | 형태 | 기본값 | 비고 |
|---|---|---|---|
| 분류 | 코드 콤보 (게시판의 분류 그룹) | 전체 | 분류 있는 게시판만 |
| 검색어 | 선택(제목 / 내용 / 제목+내용 / 작성자) + 텍스트 | 제목+내용 | |
| 작성자 구분 | 코드 콤보 `WRITER_TYPE` | 전체 | |
| 게시 여부 | 선택: 전체 / 게시 / 숨김 | 전체 | |
| 답변 상태 | 코드 콤보 `ANSWER_STATUS` | 전체 | 답글 사용 게시판만 |
| 등록기간 | 기간 | | |

**목록 칼럼**

| 칼럼 | 데이터 | 정렬 |
|---|---|---|
| 번호 | 역순 번호. 상단 고정 글은 "고정" | |
| 분류 | `CATEGORY_CD` | |
| 제목 | `TITLE` + 🔒(비밀글) + 📎(첨부) + [댓글 수] + 답글 수 | |
| 작성자 | 회원: 로그인 아이디 / 관리자: 이름 + "관리자" 표시 | |
| 답변 상태 | `ANSWER_STATUS_CD` | |
| 게시 여부 | 게시 / 숨김 | |
| 조회수 | `VIEW_CNT` | ○ |
| 등록일시 | `REG_DT` | ○ |

- 원글만 목록에 보이고, 답글은 상세에서 본다.
- 상단 고정 글은 페이지와 상관없이 맨 위에 나온다.

**버튼**: 글쓰기 (`CREATE`) → SCR-PST-03

### SCR-PST-02 게시글 상세

- URL: `/posts/{id}` · 권한: `READ`

```
┌────────────────────────────────────────────────────┐
│ [분류] 제목                              🔒 비밀글 │
│ 작성자 p_user01 · 2026-10-04 14:30 · 조회 12       │
│ 게시 여부: 게시   답변 상태: 답변대기              │
├────────────────────────────────────────────────────┤
│ 본문                                               │
│ 📎 첨부파일1.pdf (1.2MB)                           │
├────────────────────────────────────────────────────┤
│ 답글                                               │
│  └ [관리자] 홍길동 · 답글 내용 ...   [답글][수정][삭제] │
│     └ p_user01 · 재답글 내용 ...     [답글][수정][삭제] │
├────────────────────────────────────────────────────┤
│ 댓글 3                                             │
│  p_user02 · 댓글 내용                     [답글][삭제] │
│    └ [관리자] 홍길동 · 대댓글             [삭제]     │
│  [댓글 입력                              ] [등록]  │
└────────────────────────────────────────────────────┘
```

- 답글은 원글 아래에 트리로 들여쓰기해서 보여 준다. 깊이 5부터는 들여쓰기를 더 늘리지 않는다.
- 삭제된 글이 답글을 가지고 있으면 "삭제된 글입니다"로 표시한다.
- 관리자가 수정한 회원 글에는 "관리자 수정" 표시와 수정일시를 보여 준다.

**버튼 (원글·답글 공통)**

| 버튼 | 권한 | 노출 조건 | 동작 |
|---|---|---|---|
| 목록 | `READ` | 원글 | 목록으로 |
| 답글 | `CREATE` | 답글 사용 게시판 | SCR-PST-03 (답글 작성, 상위 글 = 이 글) |
| 수정 | `UPDATE` | | 회원 글이면 "사유를 입력해야 저장할 수 있습니다" 안내 후 SCR-PST-03 (수정) |
| 숨김 / 게시 | `UPDATE` | 원글 | 회원 글이면 사유 입력창, 관리자 글이면 확인창 |
| 상단 고정 / 해제 | `UPDATE` | 원글 | 바로 반영 |
| 삭제 | `DELETE` | | 회원 글이면 사유 입력창, 관리자 글이면 확인창 |
| 첨부 다운로드 | `READ` | 첨부 있음 | 파일 다운로드 |

**댓글 버튼**

| 버튼 | 권한 | 노출 조건 | 동작 |
|---|---|---|---|
| 등록 | `CREATE` | 댓글 사용 게시판 | 관리자 댓글 등록 |
| 답글 | `CREATE` | 1단계 댓글 | 대댓글 입력 칸 열기 |
| 삭제 | `DELETE` | | 회원 댓글이면 사유 입력창, 관리자 댓글이면 확인창 |

### SCR-PST-03 게시글 작성·수정

- URL: `/posts/new?board={코드}`, `/posts/new?parent={상위 글 ID}`(답글), `/posts/{id}/edit`
- 권한: 작성 `CREATE`, 수정 `UPDATE`

| 항목 | 칼럼 | 형태 | 필수 | 검증·비고 |
|---|---|---|---|---|
| 게시판 | `BOARD_ID` | 표시 | | |
| 상위 글 | `PARENT_POST_ID` | 표시 (상위 글 제목) | | 답글일 때만 |
| 분류 | `CATEGORY_CD` | 코드 콤보 | 분류 있는 게시판이면 Y | 원글만 |
| 제목 | `TITLE` | 텍스트 | Y | 200자 이내. 답글은 "RE: 상위 글 제목"을 기본값으로 |
| 내용 | `CONTENT` | 에디터 (CMP-15) | Y | |
| 상단 고정 | `TOP_FIXED_YN` | 체크박스 | | 원글만 |
| 비밀글 | `SECRET_YN` | 체크박스 | | 비밀글 허용 게시판의 원글만. 답글은 원글을 따름 |
| 게시 여부 | `DISPLAY_YN` | 라디오 | Y | 원글만. 기본 게시 |
| 첨부파일 | `TB_ATTACHMENT` | 파일 첨부 (CMP-14) | | 첨부 허용 게시판만. 개수·크기 제한 |
| 수정 사유 | (감사로그) | 텍스트 | 회원 글 수정이면 Y | 500자 이내 |

**버튼**

| 버튼 | 동작 |
|---|---|
| 저장 | 검증 → 저장 → 원글 상세로 |
| 취소 | 이전 화면으로 (입력 중이면 확인) |
