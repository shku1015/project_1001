# 05-11. 감사로그 화면

기능 명세: [04-features/11-log.md](../04-features/11-log.md) · 메뉴 코드: `AUDIT_LOG`

한 메뉴 안에 탭 두 개: [작업 로그] [로그인 이력]

## SCR-LOG-01 감사로그 (작업 로그 탭)

- URL: `/audit-logs` · 권한: `READ`

**검색 조건**

| 항목 | 형태 | 기본값 |
|---|---|---|
| 작업 기간 | 기간 (필수, 최대 3개월) | 최근 7일 |
| 관리자 | 텍스트 (로그인 아이디 또는 이름) | |
| 메뉴 | 메뉴 선택 상자 (화면 메뉴) | 전체 |
| 액션 | 코드 콤보 `ACTION` | 전체 |
| 대상 종류 | 선택 (USER, COMPANY, ROLE …) | 전체 |
| 대상 ID | 텍스트 | |

**목록 칼럼** (작업 일시 내림차순)

| 칼럼 | 데이터 |
|---|---|
| 작업 일시 | `REG_DT` (초까지) |
| 관리자 | 로그인 아이디 (이름) |
| 메뉴 | 메뉴명 |
| 액션 | `ACTION_CD` |
| 대상 | `TARGET_TYPE` / `TARGET_ID` |
| 요약 | `SUMMARY` |
| IP | `IP_ADDR` |

- 행을 누르면 상세 팝업(SCR-LOG-01-P)을 연다.

**버튼**: 엑셀 (`EXCEL`) — 변경 전·후 데이터는 빼고 다운로드

### SCR-LOG-01-P 감사로그 상세 팝업

| 영역 | 내용 |
|---|---|
| 기본 정보 | 목록 칼럼 전체 + 사유 |
| 변경 내용 | 항목 / 변경 전 / 변경 후 3열 표. 바뀐 항목만 강조. 등록이면 변경 전이 비고, 삭제면 변경 후가 빈다 |

## SCR-LOG-02 로그인 이력 탭

- URL: `/audit-logs/logins` · 권한: `READ`

**검색 조건**

| 항목 | 형태 | 기본값 |
|---|---|---|
| 기간 | 기간 (필수, 최대 3개월) | 최근 7일 |
| 로그인 아이디 | 텍스트 | |
| 결과 | 코드 콤보 `LOGIN_RESULT` | 전체 |
| 인증 방식 | 코드 콤보 `AUTH_TYPE` | 전체 |
| IP | 텍스트 | |

**목록 칼럼** (일시 내림차순)

| 칼럼 | 데이터 |
|---|---|
| 일시 | `REG_DT` (초까지) |
| 로그인 아이디 | `LOGIN_ID` |
| 관리자 | 이름 (없는 아이디면 `-`) |
| 결과 | `RESULT_CD` (실패는 빨간색) |
| 인증 방식 | `AUTH_TYPE_CD` |
| IP | `IP_ADDR` |
| 브라우저 | `USER_AGENT` 요약 (예: Chrome 130 / Windows) |

**버튼**: 엑셀 (`EXCEL`)
