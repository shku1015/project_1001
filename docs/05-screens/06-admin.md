## SCR-ADM-02 관리자 상세

- URL: `/admins/{id}` · 권한: `READ`

**표시 항목**

| 영역 | 항목 |
|---|---|
| 기본 정보 | 로그인 아이디, 이름, 이메일, 휴대폰 번호, 부서, 상태, 연속 로그인 실패 횟수, 임시 비밀번호 여부, 비밀번호 변경일시, 마지막 로그인 |
| 역할 | 부여된 역할 목록 (역할명, 부여자, 부여일시) |
| 관리 정보 | 등록자, 등록일시, 수정자, 수정일시 |
| 로그인 이력 | 최근 20건: 일시, 결과, IP |

- 관리자 정보는 개인정보 마스킹 대상이 아니다 (내부 직원 정보).

**버튼**

| 버튼 | 권한 | 노출 조건 | 동작 |
|---|---|---|---|
| 목록 | `READ` | | 목록으로 |
| 수정 | `UPDATE` | | SCR-ADM-03 (수정) |
| 역할 추가 | `UPDATE` | 본인이 아님 | 역할 선택창(사용 중인 역할 중 부여 가능한 것만) → 부여 |
| 역할 회수 | `UPDATE` | 본인이 아님, 역할이 2개 이상 | 역할 행마다 [회수] → 확인창 |
| 잠금 해제 | `UPDATE` | 잠금 상태 | 확인창 → 해제 |
| 비밀번호 초기화 | `UPDATE` | 사용중지가 아님 | 확인창 → 임시 비밀번호 표시창(CMP-09) |
| 사용중지 | `DELETE` | 본인이 아님, 사용중지가 아님 | 확인창 ("현재 로그인도 종료됩니다") → 상태 변경 |
| 재사용 | `DELETE` | 사용중지 | 확인창 → 상태 변경 |

- 보호 규칙(R3, R5)에 걸리면 버튼은 보이지만 누를 때 서버가 거부하고 이유를 알림으로 보여 준다. 화면에서 미리 판단하기 어려운 규칙이기 때문이다.

## SCR-ADM-03 관리자 등록·수정

- URL: `/admins/new`, `/admins/{id}/edit` · 권한: `CREATE` / `UPDATE`

| 항목 | 칼럼 | 형태 | 필수 | 검증·비고 |
|---|---|---|---|---|
| 로그인 아이디 | `LOGIN_ID` | 텍스트 + [중복 확인] | Y | 영문 소문자·숫자 4~50자, 중복 불가. **수정 시 표시만** |
| 이름 | `ADMIN_NM` | 텍스트 | Y | 50자 이내 |
| 이메일 | `EMAIL` | 텍스트 | Y | 이메일 형식 |
| 휴대폰 번호 | `MOBILE_NO` | 텍스트 | | 숫자 10~11자리 |
| 부서 | `DEPT_NM` | 텍스트 | | 100자 이내 |
| 역할 | `TB_ADMIN_ROLE` | 역할 체크박스 목록 | Y | **등록 시에만**. 1개 이상. 수정은 상세 화면에서 |

- 등록 후 임시 비밀번호 표시창(CMP-09)을 띄우고 상세로 간다.
