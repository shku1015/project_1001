# 05-04. 코드관리 화면

기능 명세: [04-features/04-code.md](../04-features/04-code.md) · 메뉴 코드: `CODE`

## SCR-COD-01 코드관리

- URL: `/codes` · 권한: `READ`
- 한 화면에 왼쪽 그룹코드 목록, 오른쪽 선택한 그룹의 상세코드 목록을 둔다. 등록·수정은 팝업으로 한다.

### 그룹코드 목록 (왼쪽)

**검색 조건**

| 항목 | 형태 | 기본값 |
|---|---|---|
| 그룹코드 / 그룹코드명 | 텍스트 (둘 다 검색) | |
| 사용 여부 | 선택: 전체 / 사용 / 사용 안 함 | 전체 |

**목록 칼럼** (페이징 없음, 그룹코드 오름차순)

| 칼럼 | 데이터 |
|---|---|
| 그룹코드 | `GROUP_CD` (시스템 코드는 🔒) |
| 그룹코드명 | `GROUP_NM` |
| 상세코드 수 | 건수 |
| 사용 여부 | `USE_YN` |

**버튼**

| 버튼 | 권한 | 노출 조건 | 동작 |
|---|---|---|---|
| 그룹 등록 | `CREATE` | | 그룹코드 팝업 (등록) |
| 그룹 수정 | `UPDATE` | 그룹 선택 | 그룹코드 팝업 (수정) |
| 그룹 삭제 | `DELETE` | 시스템 코드 아님, 상세코드 0건 | 확인창 → 삭제 |

### 상세코드 목록 (오른쪽)

**목록 칼럼** (페이징 없음, 정렬 순서 오름차순)

| 칼럼 | 데이터 |
|---|---|
| 코드 | `CODE` |
| 코드명 | `CODE_NM` |
| 정렬 순서 | `SORT_ORD` |
| 설명 | `DESCRIPTION` |
| 사용 여부 | `USE_YN` |

**버튼**

| 버튼 | 권한 | 노출 조건 | 동작 |
|---|---|---|---|
| 코드 등록 | `CREATE` | 시스템 코드 그룹 아님 | 상세코드 팝업 (등록) |
| 코드 수정 | `UPDATE` | 행 선택 | 상세코드 팝업 (수정) |
| 코드 삭제 | `DELETE` | 시스템 코드 그룹 아님 | "사용 안 함으로 바꾸는 것을 권장합니다" 안내가 있는 확인창 → 삭제 |

### 그룹코드 팝업

| 항목 | 칼럼 | 형태 | 필수 | 검증·비고 |
|---|---|---|---|---|
| 그룹코드 | `GROUP_CD` | 텍스트 | Y | 영문 대문자·숫자·`_`, 50자 이내, 중복 불가. **수정 시 표시만** |
| 그룹코드명 | `GROUP_NM` | 텍스트 | Y | 100자 이내 |
| 설명 | `DESCRIPTION` | 여러 줄 텍스트 | | 500자 이내 |
| 사용 여부 | `USE_YN` | 라디오 | Y | 시스템 코드는 표시만 |

### 상세코드 팝업

| 항목 | 칼럼 | 형태 | 필수 | 검증·비고 |
|---|---|---|---|---|
| 그룹코드 | `GROUP_CD` | 표시 | | |
| 코드 | `CODE` | 텍스트 | Y | 영문 대문자·숫자·`_`, 50자 이내, 그룹 안에서 중복 불가. **수정 시 표시만** |
| 코드명 | `CODE_NM` | 텍스트 | Y | 100자 이내 |
| 정렬 순서 | `SORT_ORD` | 숫자 | Y | 0 이상. 기본값: 현재 최댓값 + 1 |
| 설명 | `DESCRIPTION` | 여러 줄 텍스트 | | 500자 이내 |
| 사용 여부 | `USE_YN` | 라디오 | Y | 시스템 코드 그룹이면 표시만 |
