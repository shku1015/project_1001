## 표 읽는 법

각 화면은 아래 표로 정의한다. 해당 없는 표는 생략한다.

**검색 조건**

| 열 | 뜻 |
|---|---|
| 항목 | 화면에 보이는 이름 |
| 형태 | 텍스트, 코드 콤보(그룹코드), 기간, 선택 등 ([05-ia-screens.md](../05-ia-screens.md) 4절 컴포넌트) |
| 기본값 | 화면을 처음 열 때 값 |

**목록 칼럼**

| 열 | 뜻 |
|---|---|
| 칼럼 | 머리글 |
| 데이터 | 테이블 칼럼 또는 계산 값 |
| 정렬 | 머리글을 눌러 정렬할 수 있으면 ○ |

**입력 항목**

| 열 | 뜻 |
|---|---|
| 항목 | 화면에 보이는 이름 |
| 칼럼 | 저장할 테이블 칼럼 |
| 형태 | 텍스트, 숫자, 선택, 코드 콤보, 라디오, 체크박스, 표시(수정 불가) 등 |
| 필수 | Y = 필수 |
| 검증·비고 | 서버와 프론트가 같은 규칙으로 검증 |

**버튼**

| 열 | 뜻 |
|---|---|
| 버튼 | 버튼 이름 |
| 권한 | 필요한 액션. 없으면 버튼을 비활성으로 보여 준다 |
| 노출 조건 | 권한 외에 상태 등으로 보이는 조건 |
| 동작 | 누르면 일어나는 일 |
