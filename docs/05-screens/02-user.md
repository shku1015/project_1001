# 05-02. 사용자관리 화면

기능 명세: [04-features/02-user.md](../04-features/02-user.md) · 메뉴 코드: `USER`

## SCR-USR-01 회원 목록

- URL: `/users` · 권한: `READ`

**검색 조건**

| 항목 | 형태 | 기본값 |
|---|---|---|
| 회원 구분 | 코드 콤보 `USER_TYPE` | 전체 |
| 로그인 아이디 | 텍스트 | |
| 이름 | 텍스트 | |
| 이메일 | 텍스트 | |
| 휴대폰 번호 | 텍스트 (숫자만, 뒤 4자리 검색 가능) | |
| 소속 기업 | 텍스트 (기업명) | |
| 상태 | 코드 콤보 `USER_STATUS` | 전체 |
| 가입 경로 | 선택: 전체 / 사용자 서비스 / 관리자 등록 | 전체 |
| 가입기간 | 기간 | |

- 개인정보 항목으로 검색할 때는 마스킹 설정과 상관없이 검색되지만, 결과는 마스킹해서 보여 준다.

**목록 칼럼**

| 소속 기업 | 기업명 (개인이면 `-`) | |
| 상태 | `STATUS_CD` | |

**버튼**

| 버튼 | 권한 | 동작 |

## SCR-USR-02 회원 상세

- URL: `/users/{id}` · 권한: `READ`

**표시 항목**

| 영역 | 항목 |
|---|---|
| 기본 정보 | 회원 구분, 로그인 아이디, 상태, 가입 경로, 가입일시, 최근 로그인 일시, 탈퇴일시 |
| 개인정보 | 이름, 이메일, 휴대폰 번호, 생년월일 (마스킹 설정 따름) |
| 소속 정보 | 소속 기업(누르면 기업 상세), 부서, 직위 — 기업 회원만 |
| 관리 정보 | 등록자, 등록일시, 수정자, 수정일시 |
| 상태 변경 이력 | 변경일시, 변경 전 → 후, 사유, 처리자 (최근순) |

**버튼**

| 버튼 | 권한 | 노출 조건 | 동작 |
|---|---|---|---|
| 목록 | `READ` | | 목록으로 |
| 원문 보기 | `PRIVACY` | 마스킹된 항목이 있음 | 개인정보 원문 보기창(CMP-08) → 개인정보 영역을 원문으로 표시 |
| 수정 | `UPDATE` + `PRIVACY` | 탈퇴가 아님 | SCR-USR-03 (수정) |
| 정지 | `UPDATE` | 정상 | 사유 입력창 → 상태 변경 |
| 정지 해제 | `UPDATE` | 정지 | 사유 입력창 → 상태 변경 |
| 휴면 해제 | `UPDATE` | 휴면 | 사유 입력창 → 상태 변경 |
| 강제 탈퇴 | `UPDATE` | 탈퇴가 아님 | 사유 입력창 ("되돌릴 수 없습니다" 경고) → 상태 변경 |
| 비밀번호 초기화 | `UPDATE` | 탈퇴가 아님 | 확인창 → 임시 비밀번호 표시창(CMP-09) |
| 삭제 | `DELETE` | | 사유 입력창 → 삭제 후 목록으로 |

- 탈퇴 회원이면 상단에 "탈퇴한 회원입니다. 정보를 수정하거나 상태를 바꿀 수 없습니다"를 표시한다.

## SCR-USR-03 회원 등록·수정

- URL: `/users/new`, `/users/{id}/edit` · 권한: 등록 `CREATE` + `PRIVACY`, 수정 `UPDATE` + `PRIVACY`
- 개인정보는 원문으로 보여 준다. 수정 화면에 들어올 때 감사로그(개인정보 원문 보기, 사유 "정보 정정")를 남긴다.

**입력 항목**

| 항목 | 칼럼 | 형태 | 필수 | 검증·비고 |
|---|---|---|---|---|
| 회원 구분 | `USER_TYPE_CD` | 라디오 `USER_TYPE` | Y | **수정 시 표시만** |
| 로그인 아이디 | `LOGIN_ID` | 텍스트 + [중복 확인] | Y | 영문 소문자·숫자 4~50자, 중복 불가(삭제 회원 포함). **수정 시 표시만** |
| 이름 | `USER_NM` | 텍스트 | Y | 50자 이내 |
| 이메일 | `EMAIL` | 텍스트 | Y | 이메일 형식 |
| 휴대폰 번호 | `MOBILE_NO` | 텍스트 | | 숫자 10~11자리 |
| 생년월일 | `BIRTH_DATE` | 날짜 | | 오늘 이전 |
| 소속 기업 | `COMPANY_ID` | 기업 선택창 (정상 기업만) | 기업 회원이면 Y | 개인이면 입력 칸 숨김 |
| 부서 | `DEPT_NM` | 텍스트 | | 기업 회원만 |
| 직위 | `POSITION_NM` | 텍스트 | | 기업 회원만 |

- 등록 시 비밀번호는 입력하지 않는다. 저장하면 임시 비밀번호 표시창(CMP-09)을 띄운 뒤 상세로 간다.

**버튼**

| 버튼 | 동작 |
|---|---|
| 저장 | 검증 → 저장 → (등록이면 임시 비밀번호 표시) → 상세로 |
| 취소 | 등록이면 목록, 수정이면 상세로 |
