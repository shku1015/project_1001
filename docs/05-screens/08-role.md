**검색 조건**

| 항목 | 형태 | 기본값 |
|---|---|---|
| 역할 코드 / 역할명 | 텍스트 (둘 다 검색) | |
| 사용 여부 | 선택 | 전체 |

**목록 칼럼** (페이징 없음, 등록순)

**버튼**: 등록 (`CREATE`) → SCR-ROL-03

## SCR-ROL-02 역할 상세

- URL: `/roles/{id}` · 권한: `READ`
- 위쪽에 역할 정보, 아래쪽에 탭 두 개: [권한] [관리자]

**권한 탭**: 메뉴 트리 × 액션 체크박스 표

```
┌──────────────────────┬────┬────┬────┬────┬────┬────┐
│ 메뉴                 │조회│등록│수정│삭제│엑셀│개인│
├──────────────────────┼────┼────┼────┼────┼────┼────┤
│ ▾ 회원관리           │    │    │    │    │    │    │
│     기업정보관리     │ ☑  │ ☑  │ ☑  │ ☐  │ ☑  │    │
│     사용자관리       │ ☑  │ ☑  │ ☑  │ ☐  │ ☑  │ ☑  │
│ ▾ 게시판관리         │    │    │    │    │    │    │
│     게시판 관리      │ ☐  │ ☐  │ ☐  │ ☐  │    │    │
│   ▾ 게시판별 게시글  │    │    │    │    │    │    │
│       공지사항 관리  │ ☑  │ ☑  │ ☑  │ ☑  │    │    │
└──────────────────────┴────┴────┴────┴────┴────┴────┘
```

- 폴더 행에는 체크박스가 없다. 메뉴에서 쓰지 않는 액션 칸은 비운다.
- 체크 규칙은 SCR-PRM-01과 같다 (`READ` 자동 체크·해제, 본인이 갖지 않은 권한 체크 불가).
- 시스템 역할이거나 본인이 가진 역할이면 표를 읽기 전용으로 보여 준다.

**관리자 탭**: 이 역할을 가진 관리자 목록 (로그인 아이디, 이름, 부서, 상태, 부여일시). 행을 누르면 관리자 상세.

**버튼**

| 버튼 | 권한 | 노출 조건 | 동작 |
|---|---|---|---|
| 목록 | `READ` | | 목록으로 |
| 수정 | `UPDATE` | 시스템 역할 아님, 내 역할 아님 | SCR-ROL-03 (수정) |
| 권한 저장 | `UPDATE` | 권한 탭, 시스템 역할 아님, 내 역할 아님 | 확인창 ("이 역할을 가진 관리자 N명에게 바로 반영됩니다") → 저장 |
| 복사 | `CREATE` | | 새 역할 코드·이름 입력창 → 권한이 같은 새 역할 생성 → 새 역할 상세로 |
| 삭제 | `DELETE` | 시스템 역할 아님, 관리자 0명 | 확인창 → 삭제 후 목록으로 |

## SCR-ROL-03 역할 등록·수정

- URL: `/roles/new`, `/roles/{id}/edit` · 권한: `CREATE` / `UPDATE`

| 항목 | 칼럼 | 형태 | 필수 | 검증·비고 |
|---|---|---|---|---|
| 역할 코드 | `ROLE_CD` | 텍스트 | Y | 영문 대문자·숫자·`_`, 50자 이내, 중복 불가. **수정 시 표시만** |
| 역할명 | `ROLE_NM` | 텍스트 | Y | 100자 이내 |
| 설명 | `DESCRIPTION` | 여러 줄 텍스트 | | 500자 이내 |
| 사용 여부 | `USE_YN` | 라디오 | Y | 사용 안 함으로 바꾸면 "이 역할의 권한이 관리자 N명에게서 빠집니다" 확인 |

- 등록 후 상세 화면의 권한 탭으로 이동해 권한을 설정한다.
