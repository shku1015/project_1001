# 05-10. 마스킹 설정 화면

기능 명세: [04-features/10-masking.md](../04-features/10-masking.md) · 메뉴 코드: `MASKING`

## SCR-MSK-01 마스킹 설정

- URL: `/masking` · 권한: `READ`
- 개인정보 항목별 설정 표 하나로 구성한다. 페이징 없음.

| 칼럼 | 데이터 | 형태 |
|---|---|---|
| 개인정보 항목 | `FIELD_CD` 코드명 | 표시 |
| 마스킹 예 | 항목별 고정 예시 (예: `010-****-5678`) | 표시 |
| 화면 마스킹 | `SCREEN_MASK_YN` | 켬/끔 스위치 |
| 엑셀 마스킹 | `EXCEL_MASK_YN` | 켬/끔 스위치 |
| 마지막 수정 | `MOD_ID` 이름, `MOD_DT` | 표시 |

표 아래에 적용 규칙을 안내 문구로 보여 준다.

> - 화면 마스킹을 끄면 사용자관리 조회 권한만 있어도 원문이 보입니다.
> - 엑셀 마스킹을 꺼도 개인정보열람 권한이 있는 관리자만 원문으로 내려받습니다.

**버튼**

| 버튼 | 권한 | 동작 |
|---|---|---|
| 저장 | `UPDATE` | 바뀐 항목이 있으면 "마스킹을 끄면 개인정보가 노출됩니다" 확인창 → 저장 |

`UPDATE` 권한이 없으면 스위치를 읽기 전용으로 보여 준다.
