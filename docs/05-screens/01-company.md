# 05-01. 기업정보관리 화면

기능 명세: [04-features/01-company.md](../04-features/01-company.md) · 메뉴 코드: `COMPANY`

## SCR-COM-01 기업 목록

- URL: `/companies` · 권한: `READ`

**검색 조건**

| 항목 | 형태 | 기본값 |
|---|---|---|
| 기업명 | 텍스트 | |
| 사업자등록번호 | 텍스트 (숫자만) | |
| 대표자명 | 텍스트 | |
| 상태 | 코드 콤보 `COMPANY_STATUS` | 전체 |
| 등록기간 | 기간 | |

**목록 칼럼**

| 칼럼 | 데이터 | 정렬 |
|---|---|---|
| 번호 | 역순 번호 | |
| 기업명 | `COMPANY_NM` | ○ |
| 사업자등록번호 | `BIZ_REG_NO` (`123-45-67890`) | |
| 대표자 | `CEO_NM` | |
| 소속 회원 수 | 소속 회원 건수 (삭제 회원 제외) | ○ |
| 상태 | `STATUS_CD` | |
| 등록일시 | `REG_DT` | ○ |

**버튼**

| 버튼 | 권한 | 동작 |

| 엑셀 | `EXCEL` | 검색 결과 다운로드 |

## SCR-COM-02 기업 상세

- URL: `/companies/{id}` · 권한: `READ`

**표시 항목**: SCR-COM-03의 입력 항목 전체 + 상태, 등록자·등록일시, 수정자·수정일시

**소속 회원** (상세 아래쪽 표, 최근 가입순 10건 + [전체 보기])

| 칼럼 | 데이터 |
|---|---|
| 로그인 아이디 | `LOGIN_ID` |
| 이름 | `USER_NM` (마스킹 설정 따름) |
| 부서 / 직위 | `DEPT_NM` / `POSITION_NM` |
| 상태 | `STATUS_CD` |
| 가입일시 | `JOIN_DT` |

- 행을 누르면 회원 상세(SCR-USR-02)로 간다. [전체 보기]는 회원 목록을 이 기업으로 검색한 상태로 연다.

**버튼**

| 버튼 | 권한 | 노출 조건 | 동작 |
|---|---|---|---|
| 목록 | `READ` | | 목록으로 (검색 조건 유지) |
| 수정 | `UPDATE` | | SCR-COM-03 (수정) |
| 정지 | `UPDATE` | 상태가 정상 | 사유 입력창(CMP-07) → 상태 변경 |
| 정지 해제 | `UPDATE` | 상태가 정지 | 사유 입력창 → 상태 변경 |
| 삭제 | `DELETE` | 소속 회원이 0명 | 확인창 → 삭제 후 목록으로 |

- 소속 회원이 있으면 삭제 버튼 대신 "소속 회원이 있어 삭제할 수 없습니다"를 표시한다.

## SCR-COM-03 기업 등록·수정

- URL: `/companies/new`, `/companies/{id}/edit` · 권한: `CREATE` / `UPDATE`

**입력 항목**

| 항목 | 칼럼 | 형태 | 필수 | 검증·비고 |
|---|---|---|---|---|
| 기업명 | `COMPANY_NM` | 텍스트 | Y | 100자 이내 |
| 사업자등록번호 | `BIZ_REG_NO` | 텍스트 | Y | 숫자 10자리, 중복 불가. **수정 시 표시만** |
| 대표자명 | `CEO_NM` | 텍스트 | Y | 50자 이내 |
| 업태 | `BIZ_TYPE` | 텍스트 | | 100자 이내 |
| 종목 | `BIZ_ITEM` | 텍스트 | | 100자 이내 |
| 대표 전화번호 | `TEL_NO` | 텍스트 | | 숫자 9~11자리 |
| 주소 | `ZIP_CD`, `ADDR`, `ADDR_DTL` | [우편번호 검색] + 주소 + 상세주소 | | 우편번호·주소는 카카오 우편번호 서비스로 선택해 채우고 직접 수정 불가. 상세주소만 직접 입력 |

- 상태는 이 화면에서 바꾸지 않는다 (상세의 정지 / 정지 해제 버튼).

**버튼**

| 버튼 | 동작 |
|---|---|
| 저장 | 검증 → 저장 → 상세로 이동 |
| 취소 | 등록이면 목록, 수정이면 상세로 (입력 중이면 확인) |
