# 05-03. 메뉴관리 화면

기능 명세: [04-features/03-menu.md](../04-features/03-menu.md) · 메뉴 코드: `MENU`

## SCR-MNU-01 메뉴관리

- URL: `/menus` · 권한: `READ`
- 한 화면에 왼쪽 메뉴 트리, 오른쪽 선택한 메뉴의 상세·입력 폼을 둔다.

```
┌─────────────────────┬──────────────────────────────────────┐
│ [+ 최상위 메뉴 추가]│ 메뉴 상세                             │
│ ▾ 회원관리          │ 상위 메뉴   회원관리                  │
│    기업정보관리     │ 메뉴 코드   USER                      │
│    사용자관리   ●   │ 메뉴명      [사용자관리        ]      │
│ ▸ 게시판관리        │ 종류        화면                      │
│ ▸ 시스템관리 🔒     │ URL         [/users            ]      │
│ ▸ 관리자관리 🔒     │ 사용 액션   ☑조회 ☑등록 ☑수정 ...    │
│                     │ [하위 메뉴 추가] [상위 메뉴 변경]     │
│  [▲] [▼]            │                     [삭제] [저장]     │
│  [순서 저장][되돌리기]│                                      │
└─────────────────────┴──────────────────────────────────────┘
```

**메뉴 트리 (왼쪽)**

- 전체 메뉴를 표시한다. 사용 안 함 메뉴는 흐리게, 시스템 메뉴는 🔒, 게시판 자동 메뉴는 "자동" 표시.
- 메뉴를 고르면 오른쪽에 상세를 보여 준다.
**순서 변경**

- 두 가지 방법을 모두 제공한다.
  - 드래그: 메뉴를 끌어서 같은 상위 메뉴 안의 다른 위치에 놓는다.
  - 버튼: 메뉴를 고르고 [▲] [▼]로 한 칸씩 옮긴다.
- 드래그와 버튼 모두 **같은 상위 메뉴 안에서 순서만** 바꾼다. 다른 폴더 위에 놓아도 이동하지 않는다. 다른 폴더로 옮기려면 [상위 메뉴 변경]을 쓴다.
- 순서를 바꿔도 **바로 저장하지 않는다.** 화면의 트리만 바뀌고, 관리자가 [순서 저장]을 눌러야 저장된다.
  - 순서가 바뀐 메뉴에는 "변경됨" 표시를 하고, 트리 위에 "저장하지 않은 순서 변경이 있습니다" 안내와 [순서 저장] [되돌리기] 버튼을 보여 준다.
  - [되돌리기]는 마지막으로 저장한 순서로 트리를 되돌린다.
  - 저장하지 않은 순서 변경이 있는데 다른 화면으로 나가려 하면 확인한다.
  - 저장하지 않은 순서 변경이 있는 동안에는 메뉴 추가, 상위 메뉴 변경, 삭제를 할 수 없다. 먼저 순서를 저장하거나 되돌리도록 안내한다. (트리 구조가 바뀌는 작업과 섞이지 않게 하기 위해서다)
  - 오른쪽 상세의 메뉴명·URL 등 수정은 순서와 별개로 [저장]으로 저장한다.
- `UPDATE` 권한이 없으면 드래그와 ▲▼를 쓸 수 없다.
- 시스템 메뉴와 게시판 자동 메뉴도 순서는 바꿀 수 있다.

**메뉴 상세·입력 (오른쪽)**

| 항목 | 칼럼 | 형태 | 필수 | 검증·비고 |
|---|---|---|---|---|
| 상위 메뉴 | `PARENT_MENU_ID` | 표시 | | 최상위면 `-` |
| 메뉴 코드 | `MENU_CD` | 텍스트 | Y | 영문 대문자·숫자·`_`, 50자 이내, 중복 불가. **등록 후 표시만** |
| 메뉴명 | `MENU_NM` | 텍스트 | Y | 100자 이내 |
| 종류 | `MENU_TYPE_CD` | 라디오 `MENU_TYPE` | Y | 3단계 메뉴는 화면만 가능. **등록 후 표시만** |
| URL | `MENU_URL` | 텍스트 | 화면이면 Y | `/`로 시작. 폴더면 칸 숨김 |
| 사용 액션 | `TB_PERMISSION` | 체크박스 `ACTION` | 화면이면 Y | `READ`는 항상 체크(해제 불가). 폴더면 칸 숨김 |
| 아이콘 | `ICON` | 텍스트 | | 1단계 메뉴만 사용 |
| 사용 여부 | `USE_YN` | 라디오 | Y | 시스템 메뉴는 표시만 |

- 시스템 메뉴는 메뉴명·아이콘만 바꿀 수 있다.
- 게시판 자동 메뉴는 메뉴명·아이콘만 바꿀 수 있다 ([04-features/03-menu.md](../04-features/03-menu.md) BR-12).
- 사용 액션을 해제하고 저장할 때 그 권한을 가진 역할이 있으면 "N개 역할에서 권한이 회수됩니다"를 확인받는다.

**버튼**

| 버튼 | 권한 | 노출 조건 | 동작 |
|---|---|---|---|
| 최상위 메뉴 추가 | `CREATE` | | 오른쪽을 빈 입력 폼으로 (상위 메뉴 없음) |
| 하위 메뉴 추가 | `CREATE` | 폴더 메뉴 선택, 3단계 미만 | 오른쪽을 빈 입력 폼으로 (상위 = 선택 메뉴) |
| 저장 | `CREATE` / `UPDATE` | | 저장 후 트리 갱신 |
| 상위 메뉴 변경 | `UPDATE` | 시스템·자동 메뉴가 아님 | 폴더 메뉴 선택창 → 이동 (깊이 규칙 검사) |
| ▲ ▼ (드래그) | `UPDATE` | | 화면의 트리에서만 순서 변경 (저장 안 함) |
| 순서 저장 | `UPDATE` | 저장하지 않은 순서 변경이 있음 | 확인창 → 바뀐 상위 메뉴의 하위 메뉴 순서를 한 번에 저장 |
| 되돌리기 | `UPDATE` | 저장하지 않은 순서 변경이 있음 | 마지막 저장 순서로 되돌림 |
| 삭제 | `DELETE` | 하위 메뉴 없음, 시스템·자동 메뉴가 아님 | 확인창 → 삭제 |

- 메뉴 추가, 상위 메뉴 변경, 삭제는 저장하지 않은 순서 변경이 없을 때만 할 수 있다.
