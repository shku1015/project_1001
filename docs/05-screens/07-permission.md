# 05-07. 권한 화면

기능 명세: [04-features/07-permission.md](../04-features/07-permission.md) · 메뉴 코드: `PERMISSION`

## SCR-PRM-01 권한관리 (메뉴 기준)

- URL: `/permissions` · 권한: `READ`
- 왼쪽 메뉴 트리, 오른쪽 선택한 메뉴의 "역할 × 액션" 표.

```
┌──────────────────────┬────────────────────────────────────────────┐
│ ▾ 회원관리           │ 사용자관리 (USER)                           │
│    기업정보관리      │ ┌──────────────┬────┬────┬────┬────┬────┬────┐│
│    사용자관리   ●    │ │ 역할         │조회│등록│수정│삭제│엑셀│개인││
│ ▸ 게시판관리         │ ├──────────────┼────┼────┼────┼────┼────┼────┤│
│ ▸ 시스템관리         │ │ 슈퍼관리자 🔒│ ■  │ ■  │ ■  │ ■  │ ■  │ ■  ││
│ ▸ 관리자관리         │ │ 회원운영자   │ ☑  │ ☑  │ ☑  │ ☐  │ ☑  │ ☑  ││
│                      │ │ 조회전용     │ ☑  │ ☐  │ ☐  │ ☐  │ ☐  │ ☐  ││
│                      │ └──────────────┴────┴────┴────┴────┴────┴────┘│
│                      │                                     [저장]  │
└──────────────────────┴────────────────────────────────────────────┘
```

**메뉴 트리 (왼쪽)**: 화면 메뉴만 고를 수 있다. 폴더는 펼치기만 한다.

**역할 × 액션 표 (오른쪽)**

| 열 | 내용 |
|---|---|
| 역할 | 사용 중인 역할 전체. 사용 안 함 역할은 흐리게 |
| 액션 칸 | 메뉴의 사용 액션만 칸을 만든다. 체크 = 부여 |

- 슈퍼관리자 행은 모두 채워진 표시(■)이고 바꿀 수 없다.
- 본인이 가진 역할의 행은 바꿀 수 없다 (BR-04). 행에 "내 역할" 표시.
- 본인이 갖지 않은 권한의 칸은 체크할 수 없다 (BR-05).
- `READ`가 아닌 칸을 체크하면 같은 행의 `READ`가 자동 체크, `READ`를 해제하면 같은 행 전체가 해제된다.

**버튼**

| 버튼 | 권한 | 동작 |
|---|---|---|
| 저장 | `UPDATE` | 바뀐 칸만 저장. 저장 전 "역할 N개의 권한이 바뀝니다" 확인 |
| 관리자별 최종 권한 | `READ` | SCR-PRM-02로 이동 |

다른 메뉴를 고를 때 저장하지 않은 변경이 있으면 확인한다.

## SCR-PRM-02 관리자별 최종 권한

- URL: `/permissions/admins` · 권한: `READ`
- 관리자를 고르면(관리자 선택창 CMP-12), 그 관리자의 역할을 합친 최종 권한을 메뉴 트리 × 액션 표로 보여 준다 (조회 전용).

| 열 | 내용 |
|---|---|
| 메뉴 | 메뉴 트리 (들여쓰기) |
| 액션 칸 | ● 있음, - 없음, 빈칸은 메뉴에서 쓰지 않는 액션. 칸에 마우스를 올리면 그 권한을 준 역할 이름 표시 |

- 슈퍼관리자이면 표 대신 "슈퍼관리자는 모든 권한을 가집니다"를 표시한다.
